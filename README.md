# Настольный гуманоидный робот «MODEL-1» (FDM 3D-печать)

Проект параметрической модели настольного гуманоидного робота из печатных деталей для Blender 5.0 / Python.

## Основные файлы проекта

| Файл | Описание |
|---|---|
| **`robot_assembled.blend`** | **Полная собранная модель** робота воедино: анатомическая сборка всех узлов, текстуры, свет, камера, коллекции `ASSEMBLY` и `ELECTRONICS` |
| **`robot.blend`** | Файл с **19 отдельными деталями**, разложенными на плоскости XY (`Z_min = 0`) в оптимальной для 3D-печати ориентации |
| **`robot_assembled.png`** | Основное общее презентационное изображение собранного робота (Hero 3/4 вид, Cycles CPU) |
| **`robot_assembled_side.png`** | Боковое изображение, демонстрирующее параллельное движение рук в сагиттальной плоскости YZ |
| **`gen_assembled_robot.py`** | Скрипт генерации полной собранной модели и рендера картинок |
| **`gen_robot.py`** | Скрипт генератора печатных деталей на столе |
| **`verify_robot.py`** | Скрипт проверки геометрии и габаритов всех объектов |

## Ключевые конструкторские решения

1. **Кинематика рук (параллельно телу):**
   - Выходные валы сервоприводов плеч SG90 направлены строго по оси X наружу сквозь боковые стенки корпуса.
   - Плечевой и локтевой шарниры совершают вращение в **сагиттальной плоскости (Y-Z)**: руки совершают естественные взмахи вперёд-назад вдоль корпуса (параллельно телу), а не перпендикулярно в стороны.
2. **Усиленное крепление сервоприводов («ушки»):**
   - Сервоприводы SG90 (голова, 2 плеча, 2 локтя) надежно фиксируются отдельными прижимными планками-скобами («ушками») с крепежными отверстиями под винты M2 (межцентровое расстояние 25 мм), намертво прижимая серву к опорным буртикам кармана.
3. **Бесклеевая и безвинтовая сборка основных узлов:**
   - **Arduino Uno:** удерживается внутри тела в вертикальных направляющих пазах (ширина 2.4 мм), на боковой стенке есть окно доступа к портам USB-B и DC Jack — плата подключается и извлекается без разборки робота.
   - **Задняя крышка тела:** съемная, скользит по боковым направляющим и защелкивается замком — снимается рукой без инструментов.
   - **Ноги:** широкие устойчивые стопы 44 × 72 мм с внутренними камерами под металлический балласт (гайки, дробь, свинец) и съемными подошвенными заглушками. Фиксация к основанию тела через направляющие T-пазов (T-slot) со стопором.
   - **Голова:** посадочное гнездо под качалку шеи SG90, внутренняя полость под электронику, «глаза» под ультразвуковой дальномер HC-SR04 (Ø16.2 мм, pitch 26 мм), верхний съемный козырек.

## Габариты робота

- **Полная высота в сборе:** 253.0 мм (ноги 85 мм + зазор 3 мм + тело 110 мм + голова 55 мм) — в пределах ТЗ 250…300 мм.
- **Корпус тела (Torso):** 92.0 × 62.0 × 110.0 мм (ТЗ: 80…100 / 50…70 / 90…130 мм).
- **Толщина стенок:** 2.8 мм; посадочные зазоры FDM: 0.30…0.40 мм на сторону.

## Запуск генераторов и проверки

```bash
# Генерация файла деталей для печати (robot.blend)
blender -b -P gen_robot.py

# Генерация полной собранной модели и рендеров (robot_assembled.blend + png)
blender -b -P gen_assembled_robot.py

# Проверка габаритов в headless-режиме
blender -b -P verify_robot.py
```
