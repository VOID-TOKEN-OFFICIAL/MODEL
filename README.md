# MODEL — настольный гуманоидный робот «MODEL-1» (FDM-детали)

Готовый файл — **`robot.blend`**: сцена Blender в миллиметрах (`METRIC / MILLIMETERS / scale_length 0.001`,
то есть 1 единица файла = 1 мм). Все детали получены булевыми операциями (solver `EXACT`, модификаторы
применены), каждая деталь — отдельный именованный объект.

| Коллекция | Содержимое |
|---|---|
| `PRINT_BED` | 17 напечатанных деталей (12 уникальных), разложены рядом на плоскости XY как на столе печати: каждая в ориентации печати, низ детали на Z = 0 |
| `ASSEMBLY` | те же детали (те же меш-данные) в положении сборки |
| `PHANTOM` | габаритные «фантомы»: 5 × SG90, 5 качалок, Arduino Uno (не печатаются, показаны для контроля компоновки) |

Габариты в сборе: **218 × 63.5 × 272.5 мм** (высота в ТЗ 250…300 мм), тело **94 × 62 × 121 мм**
(ТЗ 80-100 / 50-70 / 90-130 мм), стойка ног 98 × 44 мм. Стенки 2.8 мм, посадочные зазоры FDM
0.30…0.35 мм на сторону.

## Компоновка

* **12 уникальных деталей:** `Torso_Tub`, `Neck_Plate`, `Back_Cover`, `Head_Shell`, `Upper_Arm_R/L`,
  `Forearm_R/L`, `Leg_R/L`, `Sole_Plate`, `Servo_Shoe` (5 экземпляров — плечи, локти, шея).
* **5 сервоприводов SG90** (по ТЗ): плечи — вал наружу через боковую стенку тела, локти — вал из первого
  звена руки во второе, шея — вал вертикально вверх из тела.
* **Без клея и винтов** (кроме штатного винтика качалки из комплекта сервы): пазы, шипы, язычковые
  защёлки, штифты, направляющие, пробки-штифты из обрезка филамента Ø1.75.
* **Arduino Uno** живёт в корпусе на двух полках-направляющих и центральном ребре, фиксируется
  упор-губой и подпружиненным усиком, вынимается за разъём без разборки робота (окно доступа к
  USB-B и питанию — в правой стенке).
* **Ноги полые** под стальные утяжелители Ø16 × 52 мм; снизу — съёмная заглушка подошвы
  (посадка с натягом рёбер, прорезь под ноготь).
* **Трассы проводов** (пучок Ø8-10 / одиночный Ø1.5): низ → тело через отверстие Ø10 в дне,
  тело → голова через Ø10 в плите шеи и Ø10 в основании головы, тело → руки через окна 12 × 8 мм
  в боковых стенках (скрыты за звеньями рук).

## Файлы

| Файл | Назначение |
|---|---|
| `robot.blend` | **результат**: сцена с деталями, сборкой, фантомами, светом и камерами |
| `gen_robot.py` | генератор модели (Blender Python, все размеры — именованные параметры в шапке) |
| `inspect_blend.py` | headless-проверка: открывает `robot.blend` и печатает список объектов с габаритами в мм |
| `check_assembly.py` | контроль сборки: считает объём взаимных пересечений всех деталей (булево `INTERSECT`) |
| `render_check.py` | контрольные рендеры сборки и раскладки (Cycles, CPU) |
| `r_front.png`, `r_three.png`, `r_bed.png` | контрольные изображения |

## Пересборка и проверка

```bash
# вариант 1: обычный Blender
blender -b -P gen_robot.py            # пересобрать robot.blend + таблица габаритов
blender -b robot.blend -P inspect_blend.py
blender -b robot.blend -P check_assembly.py

# вариант 2: pip-пакет bpy (использовался при разработке)
pip install bpy
python gen_robot.py && python inspect_blend.py && python check_assembly.py
```

## Порядок сборки

1. `Servo_Shoe` ×5 надеть на корпуса серв (ушко прижато к плоскости «туфли»), качалки закрепить
   на валах штатными винтиками.
2. Плечевые сервы вставить снаружи «туфлями» вперёд: ушки в выборку стенки, штифты стенки войдут
   в отверстия ушек; кабель — в прорезь кромки окна.
3. `Torso_Tub` + `Neck_Plate` (защёлки) + `Back_Cover` (защёлки, пробки филамента в 4 отверстия).
4. `Upper_Arm_R/L` надеть ступицей на качалку плеча (крестовой паз кармана входит на перо качалки),
   затем `Forearm_R/L` — на качалку локтя.
5. Ноги: шип торса вставить в гнездо ноги — язычковые защёлки фиксируют; утяжелитель в полость,
   закрыть `Sole_Plate`.
6. `Head_Shell` надеть снизу на качалку сервы шеи; поворот головы — посадкой с зазором 0.5 мм.

## Допущения (в ТЗ не заданы)
